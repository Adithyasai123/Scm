AI-Native UI Developer Hackathon
Challenge: Build an AI-Generated Sales Channel Management Portal
Objective
Build a 
production-quality responsive web application
 for the Sales Channel Management (SCM) system using the supplied 
SCM_APIs.postman_collection.json
 as the API contract.
The candidate must use an 
AI coding agent as the primary development mechanism
.
The challenge is intentionally designed to evaluate:
Requirement → AI Prompt → UI Design → AI Implementation → API Integration → AI Tests → Validation → AI-assisted Debugging → Human Code Review
This follows the expected development philosophy in the AI-Native UI Engineer role.

6. Part B — OTP Workflow
This is an important evaluation area.
The candidate must understand and implement the OTP workflow rather than treating each API independently.
The collection states that most write operations follow:
Send OTP
     ↓
Enter OTP
     ↓
Validate OTP
     ↓
Perform Mutation
     ↓
Success
The Postman collection explicitly defines Send OTP and Validate OTP operations and uses operation/topic combinations for different business operations.
UI expectation
When a user performs a protected operation:
Step 1
Display confirmation.
Step 2
Trigger Send OTP.
Step 3
Display OTP modal.
Step 4
Validate OTP.
Step 5
Execute the requested mutation.
Step 6
Display success/failure.
The UI should prevent the mutation from being submitted before successful OTP validation.
